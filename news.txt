# Star Wars Trilogy Native: what is new, for the players.
#
# NicoLauncher shows this file from GitHub (main branch, hub.toml: news) and
# offers the update. Commits that do not add an entry show nothing, so several
# fixes can go out together: add the entry when they are all in.
#
# Format:
#   [N] title      starts entry N (a number one higher than the last; the
#                  title is usually the date)
#   - text         a line of the entry (lines starting "- " get a bullet)
#   # ...          a comment, never shown
# Newest entry at the top. Keep each one short: about ten lines fit.

[29] 2026-11-28
- New TELEMETRY option (OPTIONS > EXPERIENCE > EXPERIMENTAL) for motion rigs and haptics: the craft's motion in the flights, the shield, the score and every hit, in the OGS-TS format (Open Game Standards), thanks to Brian Gilbert. Not tested on a real rig yet

[28] 2026-11-27
- Hoth base (the tunnels and the hangar): in widescreen the sight now reaches the sides of the screen, with the mouse, a light gun or a pad, as on the snow
- Mouse and light gun: the sight lands right under the pointer across the whole screen, in every stage and at any WIDESCREEN setting

[27] 2026-11-26
- PLAY now shows a LOADING screen while the game gets ready. Esc, or B / BACK on the pad, goes back to the main menu while it loads, and the next PLAY then starts at once
- Laser shots, lightsabers, engines and fire no longer cast sun shadows

[26] 2026-11-25
- Behind the scenes: a big tidy-up of the code, about 4,000 lines fewer. Nothing changes in how the game looks or plays

[25] 2026-11-24
- New OPTIONS page, in the style of Sega Rally 2: EXPERIENCE, DISPLAY, GRAPHICS, AUDIO and CONTROLS, with what each setting does in a panel at the right. RECORDS uses the same page
- PLAY lists ARCADE CLASSIC and DOGFIGHT (coming soon); the EXTRA MODES screen and the QUALITY presets are gone
- DISPLAY: window, borderless or full screen at the resolution you pick, RENDER SCALE, VSYNC (ON / ADAPTIVE / OFF), MAX FPS, a frame limit while another window has the focus, and WIDESCREEN AUTO to fill any window
- NVIDIA RTX: DLSS (QUALITY to ULTRA PERFORMANCE) with dynamic resolution, besides DLAA. Other cards get FXAA
- Settings that need a restart now offer RESTART NOW
- Every setting opens a list of all its values: click the row (away from its arrows) or press Enter / A
- Xbox pads: TRIGGER RUMBLE, the motors in the triggers on shots and reloads
- ARCADE ORIGINAL (OPTIONS > EXPERIENCE): the cabinet as it was, from the SEGA logo and the attract, coin and START to play, the original look and sound, in 4:3 or widescreen. Esc pauses
- Updates now come only through NicoLauncher: the game no longer checks GitHub itself (update.bat still works)

[24] 2026-11-21
- Fire, explosions and the glow around lights: no more grain over them or noisy edges when AMBIENT OCCLUSION and SOFT PARTICLES are on

[23] 2026-11-21
- Linux: the game now builds and runs on Linux too, on PCs (x86_64) and arm64 boards such as the Raspberry Pi 5, thanks to vojenfr (steps in docs/LINUX.md)
- Windows: small renderer start-up changes shared with the Linux version, nothing else changes
- Installing: with the wrong swtrilgy.zip the build now says which set it is (the original release or the prototype instead of Rev. A), and a swtrilgy.zip inside another zip is used as it is

[22] 2026-11-20
- NVIDIA RTX: DLAA now works in installs made with NicoLauncher, which until now quietly used MSAA instead. Press Update in the launcher to get it (it downloads about 60 MB from NVIDIA)

[21] 2026-11-18
- Endor: the shield bunker explosion at 16:9 no longer breaks along a diagonal line, and its sky now fills the whole width
- ULTRA: no more stripes from the ray traced shading on walls, most visible in the throne room
- Death Star 2: the reactor room no longer flashes brighter every few frames

[20] 2026-11-17
- Smoother play on slow drives (external SSD, USB stick, or an antivirus that scans every file): stats, achievements and the game's settings memory are now saved in the background, so saving no longer stops the game for a moment

[19] 2026-11-17
- Flight sticks such as the X56 HOTAS, and older gamepads that are not Xbox or PlayStation pads, are now detected when the game is installed with NicoLauncher

[18] 2026-11-16
- New main menu: the Nico SWT logo, smaller, with PLAY big at the top, as in The Lost World and Sega Rally 2
- The description of the chosen entry now opens right under it
- MORE RECOMPS is gone from the menu: get The Lost World and Sega Rally 2 from NicoLauncher (github.com/snicolast/NicoLauncher-Hub)
- New yellow SWT icon for the game

[17] 2026-11-15
- Updating is more reliable: an update now always recompiles every file that changed, so it no longer fails to build when the game was updated more than once in a short time

[16] 2026-11-15
- Widescreen: the results screen at the end of each stage is no longer cut in two and missing text (a regression from the previous update)
- Menus: the game no longer draws the 3D scene hidden behind them, so the GPU (and its fans) stay quiet in the main menu

[15] 2026-11-14
- Hoth base: with MOTION: SMOOTH, the capes of fallen snowtroopers no longer stretch across the screen
- Widescreen: the HUD no longer jumps back to 4:3 when you get hit or a SUCCESS counter appears in duels
- NicoLauncher now shows your achievements on the game's page
- The achievements are also saved to achievements/achievements.csv, ready to import into PlayniteAchievements (Editor, Spreadsheet Import)

[14] 2026-11-12
- NicoLauncher is out: one free app that installs, builds, updates and starts this game and the other recomps. No Visual Studio needed
- Get it at github.com/snicolast/NicoLauncher-Hub. Your current install keeps working, and the launcher can use the folder you already have
- Menu music now plays through the game's own sound output: no more silent menus on some PCs

[13] 2026-11-11
- No more console window behind the game
- Building: fixed a Visual Studio setup error on PCs with an unusual PATH, and the NVIDIA DLSS download is now optional

[12] 2026-11-11
- Sega Rally 2 is out, recompiled for PC like this one: it is now in the main menu under MORE RECOMPS, beside The Lost World
- If it is in a folder next to this one, ENTER starts it; if not, ENTER opens its page, where you can download it

[11] 2026-11-11
- Hoth base: the shadows of C-3PO and R2-D2 on the floor are black again, not coloured copies of the droids
- The build now finds a Python 3.10 or later by itself, so it no longer fails with an older Python or the Microsoft Store one
- build.bat tries the SDL3 and miniz downloads again when the connection drops

[10] 2026-11-09
- New explosions in Yavin: fireballs that billow and burn out into smoke, sparks, burning debris, and TIE fighters breaking into real pieces of themselves
- Each explosion looks a little different, and its sound is louder, deeper and comes from where it is on the screen
- On by default; OPTIONS > GRAPHICS > EXPLOSIONS: ARCADE brings back the original ones
- Lightsaber duels: arms and sabre no longer go missing, and INVERT IN DUELS now works, in every game
- The game now starts on Intel UHD graphics (laptops) that failed with "Could not start the 3D renderer"

[9] 2026-11-09
- Flight sticks (Thrustmaster T.Flight HOTAS and the like) now work: the stick is the cabinet's lever, button 1 fires, 2 is the second trigger, 3 EVENT, 4 coin, 5 start

[8] 2026-11-08
- Mac: the game now builds on Apple silicon Macs too, thanks to Nutcasey (steps in docs/MACOS.md)
- Windows: a small renderer change shared with the Mac version, nothing else changes

[7] 2026-11-08
- OPTIONS > CONTROLS > INVERT IN DUELS: turn the aim round in the lightsaber duels only, if they feel the wrong way round (the other stages stay as they are)

[6] 2026-11-08
- OPTIONS > DISPLAY > WIDESCREEN: 4:3, 16:9, 21:9, 32:9, or 48:9 for three monitors side by side
- install.bat adds the Windows SDK when it is missing; build.bat says when there is none
- build.bat downloads the DLSS files again when one of them is missing
- If the 3D renderer cannot start, the log says which step failed

[5] 2026-11-07
- The gamepad sticks respond better: small pushes move the sight, so it no longer feels laggy
- STICK AIM LEVER swings over faster
- GYRO AIM now starts off (turn it on in OPTIONS > CONTROLS); if you played before, your setting stays as it was

[4] 2026-11-07
- The ice cave in the Hoth base (snowtroopers before the Falcon) is no longer drawn almost black

[3] 2026-11-07
- The droids in the Hoth base are no longer drawn black
- Endor's planet in the last stage no longer shows grey squares
- install.bat finds the C++ tools right after installing them, before Windows restarts
- install.bat updates Visual Studio when its CMake is too old to build the game

[2] 2026-11-06
- The menus show the gamepad's buttons when you use a controller, and the keys again when you use the keyboard
- Xbox button icons by ElDuderino (CC0)
- Y on the gamepad opens The Lost World's GitHub page in MORE RECOMPS
