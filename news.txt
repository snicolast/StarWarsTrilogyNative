# Star Wars Trilogy Native: what is new, for the players.
#
# The game reads this file from GitHub (main branch) at launch. When it has an
# entry with a higher number than the news.txt in the player's folder, the main
# menu shows those entries in an UPDATE AVAILABLE window with UPDATE NOW
# (update.bat) and LATER. Commits that do not add an entry show nothing, so
# several fixes can go out together: add the entry when they are all in.
#
# Format:
#   [N] title      starts entry N (a number one higher than the last; the
#                  title is usually the date)
#   - text         a line of the entry (lines starting "- " get a bullet)
#   # ...          a comment, never shown
# Newest entry at the top. Keep each one short: about ten lines fit.

[12] 2026-11-11
- Sega Rally 2 is out, recompiled for PC like this one: it is now in the main menu under MORE RECOMPS, beside The Lost World
- If it is in a folder next to this one, ENTER starts it; if not, ENTER opens its page, where you can download it

[11] 2026-11-11
- Hoth base: the shadows of C-3PO and R2-D2 on the floor are black again, not coloured copies of the droids
- The build now finds a Python 3.10 or later by itself, so it no longer fails with an older Python or the Microsoft Store one
- build.bat tries the SDL3 and miniz downloads again when the connection drops

[10] 2026-11-09
- New explosions in Yavin: fireballs that billow and burn out into smoke, sparks, burning debris, and TIE fighters breaking into real pieces of themselves
- Each explosion looks a little different, and its sound is louder, deeper and comes from where it is on the screen
- On by default; OPTIONS > GRAPHICS > EXPLOSIONS: ARCADE brings back the original ones
- Lightsaber duels: arms and sabre no longer go missing, and INVERT IN DUELS now works, in every game
- The game now starts on Intel UHD graphics (laptops) that failed with "Could not start the 3D renderer"

[9] 2026-11-09
- Flight sticks (Thrustmaster T.Flight HOTAS and the like) now work: the stick is the cabinet's lever, button 1 fires, 2 is the second trigger, 3 EVENT, 4 coin, 5 start

[8] 2026-11-08
- Mac: the game now builds on Apple silicon Macs too, thanks to Nutcasey (steps in docs/MACOS.md)
- Windows: a small renderer change shared with the Mac version, nothing else changes

[7] 2026-11-08
- OPTIONS > CONTROLS > INVERT IN DUELS: turn the aim round in the lightsaber duels only, if they feel the wrong way round (the other stages stay as they are)

[6] 2026-11-08
- OPTIONS > DISPLAY > WIDESCREEN: 4:3, 16:9, 21:9, 32:9, or 48:9 for three monitors side by side
- install.bat adds the Windows SDK when it is missing; build.bat says when there is none
- build.bat downloads the DLSS files again when one of them is missing
- If the 3D renderer cannot start, the log says which step failed

[5] 2026-11-07
- The gamepad sticks respond better: small pushes move the sight, so it no longer feels laggy
- STICK AIM LEVER swings over faster
- GYRO AIM now starts off (turn it on in OPTIONS > CONTROLS); if you played before, your setting stays as it was

[4] 2026-11-07
- The ice cave in the Hoth base (snowtroopers before the Falcon) is no longer drawn almost black

[3] 2026-11-07
- The droids in the Hoth base are no longer drawn black
- Endor's planet in the last stage no longer shows grey squares
- install.bat finds the C++ tools right after installing them, before Windows restarts
- install.bat updates Visual Studio when its CMake is too old to build the game

[2] 2026-11-06
- The menus show the gamepad's buttons when you use a controller, and the keys again when you use the keyboard
- Xbox button icons by ElDuderino (CC0)
- Y on the gamepad opens The Lost World's GitHub page in MORE RECOMPS
